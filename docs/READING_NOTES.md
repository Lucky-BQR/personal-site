# 读书笔记：使用与边界

入口：笔记花园 → 记读书笔记，或记录与写作 → 打开读书笔记（`/write/reading`）。

- 先建书：添加书名、作者和阅读缘起，进入书籍后点「记这本书」。
- 先记内容：点「随手记一段」，书籍可以留空。以后编辑笔记时选择书籍即可归入。
- 每篇笔记分开保存章节/页码、原文摘录、个人理解和标签。标题留空时取理解或摘录的开头。
- 按书浏览，搜索书名、作者、章节、摘录、理解和标签。支持 Markdown、图片、单篇导出。
- 完整 JSON 备份保留书籍、归属、摘录和图片；单篇 Markdown 是便携阅读文件，归档恢复请用 JSON。

## 与已有内容的关系

读书笔记用于持续阅读与零散积累；笔记花园中的「读书观影」仍是公开文章筛选。学习记录适用于课程和其他所学。生活承载日常和兴趣。中医沿用原有独立笔记本，未迁移数据。

## 当前保存范围

本次功能沿用 IndexedDB 本机存储，不上传，也不自动公开。不具备账号鉴权或跨设备同步；共用同一浏览器的人可以读取。它不是服务端私密空间。登录、数据库访问控制和主动公开仍待单独实施。

书籍使用 reading.kind=book，笔记使用 reading.kind=note，保存在原 records store；不升级或清空现有数据库。旧备份仍可导入，恢复时保留同编号的现有内容。书籍不计入最近在写与每周记录数。
