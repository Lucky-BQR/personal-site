## 内容来源

- 公开文章：content/garden/*.mdx。category 支持 technology、reading、reflection；status: published 才公开。分类筛选从网址读取，支持刷新与前进后退。
- 项目：content/projects/*.mdx。列表与详情共用同一份内容；详细设计可展开阅读。
- 关于：content/creator/story.mdx。
- 时间线：content/timeline/*.mdx。保留原有锚点。
- 哲学已有条目保留，未提供正文时明确显示“待整理”。
- 友链尚无真实内容，显示空状态，不发布设计稿里的示例。
- 中医：当前浏览器 IndexedDB，保留书籍、笔记、原图、导入导出与备份功能。
- 生活栏目：统一使用独立 IndexedDB 数据库 zhuqing-life-notebook，支持新增、查看、编辑、删除、搜索。包含书法赏析、诗歌、音乐、自己的书法、宠物、灵感、创作与链接。
- 旧灵感首次打开时从原 localStorage 无损迁移，保留原始存储值；迁移标记与记录在同一事务提交，删除已迁移的记录后不会重新出现。
- 创作入口 /life/writing，支持草稿／定稿筛选；链接入口 /life/links，保存个人主页或收藏网址。它们都归属生活。
- 各栏目正文统一使用 Markdown，支持预览、上传／粘贴图片、导入与导出 .md。导出的图片内嵌在 Markdown 文件中，导入时恢复为本地附件；相对图片路径仍需手动补充图片。
- 每个列表底部「备份与导入」导出全部生活记录和图片为 JSON。导入先校验全文件，再用事务一次提交；同编号记录保留本机版本，不覆盖。要恢复已存在条目的历史版本，先备份当前记录，再删除该条并导入旧备份。
- 编辑采用版本检查，防止其他标签页的旧编辑覆盖新记录。修改需要点击保存；离开链接或刷新时提示尚未保存的修改。
- 中医和生活记录不会随 Git 推送公开，也不会自动跨设备同步。浏览器按来源隔离数据，localhost、线上域名和其他设备的记录互相独立；迁移时使用导出／导入。清除网站数据会删除本机记录，请保留外部备份。
- 数据转换与迁移回归检查：npm run life:verify；部署前自动执行。

## 本地预览与部署

使用 Node.js 22 或更新的兼容 LTS。安装依赖 npm ci，开发 npm run dev。
生产预览先构建 npm run build，再 npm run preview，默认端口 3100。
GitHub Pages 构建时设 GITHUB_PAGES=true，预览地址使用 /personal-site/ 前缀。
推送 main 会通过 GitHub Actions 构建并发布；其他分支不部署。

## 设计原则

保留现有米白、竹青与字号。详情页居中，去掉普通文章的重复推荐模块；不添加装饰竹叶和深绿页尾。
所有子页标明返回位置，导航高亮所属栏目。无内容时保持自然留白。
