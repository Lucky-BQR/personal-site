# 竹青小筑 AI 开发任务模板

> 用于辅助 Codex 进行项目迭代。
>
> 默认遵循项目根目录 AGENTS.md 中定义的：
> - 项目定位
> - 设计原则
> - 开发规范
> - 内容理念


---

# 使用原则

执行任何任务前：

1. 先理解当前代码结构
2. 判断影响范围
3. 优先选择最小修改方案


默认要求：

- 不随意重构
- 不引入无必要依赖
- 优先复用已有组件
- 保持代码可维护
- 保持 TypeScript 类型安全
